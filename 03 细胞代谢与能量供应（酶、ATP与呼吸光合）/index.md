# 03 细胞代谢与能量供应（酶、ATP与呼吸光合）

> 本专题属于 **高中生物知识库** 的绝对核心动力模块，严格对齐人教版高中生物必修1第5章，以生物热力学、能量偶联与生化微区室化为底层主线，彻底贯通酶催化、ATP 货币循环、细胞呼吸与光合作用的高考大题与压轴计算。

## 🧭 专题生命观念与认知导航

本专题从能量流动与物质转化的最高维度揭示生命的动态平衡本源：
1. **能垒与生物催化**：酶通过显著降低活化能驱动常温常压下的生化网络，专一性与温和性维系了细胞代谢的有序运转。
2. **能量通货与偶联机制**：ATP 巧妙的末端高转移势能化学键，通过放能反应合成、吸能反应水解，实现了跨微区室的微观能量无缝充放电。
3. **呼吸分步释放**：从细胞质基质的糖酵解，到线粒体基质的彻底脱羧，再到线粒体内膜的电子传递链，能量以极高效率被捕获为 ATP，杜绝了热爆破。
4. **光合捕碳建桥**：光反应在类囊体薄膜上光解水并将光能转化为 ATP 与 NADPH，碳反应在叶绿体基质中通过 Rubisco 酶固定二氧化碳，构建起地球生物圈最宏伟的碳循环基础。
