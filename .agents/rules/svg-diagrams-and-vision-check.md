# 生物矢量 SVG 设计与多模态视觉核验协议

## 1. SVG 画布、布局与防重叠设计

- **统一视口标准**：统一使用 `viewBox="0 0 780 370"`，兼顾 VitePress 移动端自适应响应与桌面端高保真展示。
- **专业配色体系**：采用深色 Slate 顶部标题条、白色/淡绿/淡蓝双列卡片、标准科学矢量色（绿色叶绿体/植物/正常表型、红色线粒体/血流/显性基因/突变、蓝色水/膜结构/隐性基因、橙色酶/ATP/中间产物）。
- **局部坐标系防叠字准则**：
  - 多卡片纵向排布或代谢通路分步时，**必须使用 `<g transform="translate(0, Y)">` 建立独立局部坐标系**，严禁在根坐标系中直接写入硬编码的绝对 Y 坐标，以杜绝多段生理生化文本、物质流向箭头与标注相互重叠。
  - 生物结构、系谱图、质粒环形图标注文本与卡片外框之间至少保留 10px 的安全留白，避免边缘截断。

## 2. 闭环多模态视觉化质检流程

- **强制光栅化渲染**：
  - 任何新增或重构的生物 SVG 图解（如光合呼吸双反应、减数分裂染色体行为、系谱图分析、内环境物质交换、PCR 循环图谱等），不得仅依靠代码审查，必须调用 Playwright / 无头 Chrome 渲染脚本将 SVG 输出为 2x 高清 PNG。
- **多模态视觉质检核验**：
  - 使用 `view_file` 对渲染出的 PNG 截图进行视觉质检：
    1. 检查文字两端是否被卡片边框截断；
    2. 检查反应流动箭头是否穿透文字或遮挡生物学物质符号；
    3. 检查细胞器、染色体形态等图元内部的标注字符是否与边缘线条重叠。
  - 若发现瑕疵，立即微调 SVG 坐标，重新光栅化复验，直到视觉达到顶级科普与教材级出版品质。
