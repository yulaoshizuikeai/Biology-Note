# 02 两对相对性状杂交实验与9331变式全景矩阵

> **【导读与第一性原理】**
> - **教材坐标**：必修2 第1章 第2节《孟德尔的豌豆杂交实验（二）》
> - **核心生命观念**：信息观、系统与模型建构、概率与统计第一性原理
> - **认知引导**：如果说分离定律是研究“单个硬币抛掷”的概率守恒，那么自由组合定律就是“多枚硬币同时独立抛掷”的笛卡尔积。孟德尔发现，无论子叶是黄是绿，种皮是圆是皱，两对性状在遗传中互不干扰、各自独立分配。然而，高考绝不仅仅止步于经典的 $9:3:3:1$，当基因编码的酶处于同一生化合成通路的上下游，或者特定基因型导致胚胎/配子死亡时，这 16 格棋盘就会发生奇妙的“折叠”与“聚类”。本节将带你掌握化繁为简的**拆分法**，穿透 $9:7$、$9:3:4$、$15:1$ 等变式迷宫。

## 一、 教材基础与核心机理透析

### 1. 两对相对性状杂交实验的过程与逻辑

#### (1) 实验现象与问题提出
$$\text{P: 纯种黄色圆粒}(YYRR) \times \text{纯种绿色皱粒}(yyrr) \longrightarrow \text{F}_1: \text{黄色圆粒}(YyRr)$$
- $\text{F}_1$ 植株自交，$\text{F}_2$ 出现 **4 种表现型**：
  - 黄色圆粒（双显）：$315$ 株（约 $\frac{9}{16}$）
  - 黄色皱粒（单显）：$101$ 株（约 $\frac{3}{16}$，亲本重组类型）
  - 绿色圆粒（单显）：$108$ 株（约 $\frac{3}{16}$，亲本重组类型）
  - 绿色皱粒（双隐）：$32$ 株（约 $\frac{1}{16}$）
- **核心规律**：两对性状分别统计：
  - 粒色：黄色 : 绿色 $= (315 + 101) : (108 + 32) = 416 : 140 \approx 3 : 1$；
  - 粒形：圆粒 : 皱粒 $= (315 + 108) : (101 + 32) = 423 : 133 \approx 3 : 1$。
  - 每对相对性状均严格遵循**分离定律**！

#### (2) 假说解释与 16 种受精组合
1. $\text{F}_1$（$YyRr$）在形成配子时，每对等位基因彼此分离，不同对的等位基因自由组合。
2. $\text{F}_1$ 产生 4 种雄配子和 4 种雌配子：$YR : Yr : yR : yr = 1 : 1 : 1 : 1$。
3. 受精时，雌雄配子随机结合，产生 **16 种结合方式**，对应 **9 种基因型**、**4 种表现型**。

```
     YR(1/4)      Yr(1/4)      yR(1/4)      yr(1/4)
YR  YYRR(黄圆)   YYRr(黄圆)   YyRR(黄圆)   YyRr(黄圆)
Yr  YYRr(黄圆)   YYrr(黄皱)   YyRr(黄圆)   Yyrr(黄皱)
yR  YyRR(黄圆)   YyRr(黄圆)   yyRR(绿圆)   yyRr(绿圆)
yr  YyRr(黄圆)   Yyrr(黄皱)   yyRr(绿圆)   yyrr(绿皱)
```

#### (3) 自由组合定律的细胞学实质
- **发生时期**：减数第一次分裂后期（减Ⅰ后期）。
- **微观行为**：**同源染色体彼此分离**（等位基因分离），同时**非同源染色体自由组合**（位于非同源染色体上的非等位基因自由组合）。

## 二、 高考高频定量计算与数学模型

### 1. 拆分法（独立事件乘法原理）──解题第一利器

将多对基因自由组合问题，直接拆解为独立的一对等位基因分离问题分别计算，最后相乘：
- **基因型拆分**：$YyRr \times YyRr \Rightarrow (Yy \times Yy) \times (Rr \times Rr)$
  - 基因型种类：$3 \times 3 = 9$ 种；
  - 纯合子概率：$(\frac{1}{2}) \times (\frac{1}{2}) = \frac{1}{4}$（含 $YYRR, YYrr, yyRR, yyrr$ 各 $\frac{1}{16}$）；
  - 双杂合子概率：$YyRr = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$。
- **表现型拆分**：
  - 表现型种类：$2 \times 2 = 4$ 种；
  - 双显性（$Y\_R\_$）$= \frac{3}{4} \times \frac{3}{4} = \frac{9}{16}$；
  - 单显性（$Y\_rr$ 或 $yyR\_$）$= \frac{3}{4} \times \frac{1}{4} = \frac{3}{16}$；
  - 双隐性（$yyrr$）$= \frac{1}{4} \times \frac{1}{4} = \frac{1}{16}$。

### 2. $9:3:3:1$ 变式全景矩阵（破译加和为 16 的上位与互补变式）

高考常考由于**基因互作（Epistasis）**导致的表型合并。识别关键：**只要子代各种表型比例之和等于 16（或测交比之和等于 4），两对基因必位于非同源染色体上，遵循自由组合定律！**

| $\text{F}_2$ 表现型比例 | 对应基因型归类合并 | 测交后代比例 | 生物学机理 / 经典考题原型 |
| :--- | :--- | :---: | :--- |
| **$9 : 3 : 3 : 1$** (经典) | $A\_B\_(9) : A\_bb(3) : aaB\_(3) : aabb(1)$ | $1:1:1:1$ | 经典豌豆粒色粒形，两对性状互不干涉 |
| **$9 : 7$** (互补效应) | $A\_B\_(9) : [A\_bb(3) + aaB\_(3) + aabb(1)](7)$ | $1:3$ | **两酶协作模型**：生化途径需酶A与酶B共同催化才产色素（如香豌豆花色） |
| **$9 : 3 : 4$** (隐性上位) | $A\_B\_(9) : A\_bb(3) : [aaB\_(3) + aabb(1)](4)$ | $1:1:2$ | **前体阻断模型**：$aa$ 缺少前体合成酶，导致 $B$ 基因无法表达（如家兔毛色黑/棕/白） |
| **$9 : 6 : 1$** (加性效应) | $A\_B\_(9) : [A\_bb(3) + aaB\_(3)](6) : aabb(1)$ | $1:2:1$ | **显性累加模型**：单显（$A$ 或 $B$）效果相同，双显产生增强效应（如南瓜盘状/球状/长柱状） |
| **$15 : 1$** (重复基因) | $[A\_B\_(9) + A\_bb(3) + aaB\_(3)](15) : aabb(1)$ | $3:1$ | **功能冗余模型**：$A$ 或 $B$ 只要有一个显性基因即可催化同一步骤（如荠菜三角形/卵形果实） |
| **$12 : 3 : 1$** (显性上位) | $[A\_B\_(9) + A\_bb(3)](12) : aaB\_(3) : aabb(1)$ | $2:1:1$ | $A$ 基因显性存在时会抑制或覆盖 $B$ 基因的表现 |
| **$13 : 3$** (显性上位抑制) | $[A\_B\_(9) + aaB\_(3) + aabb(1)](13) : A\_bb(3)$ | $3:1$ | 显性抑制因子模型（如鸡羽毛显性白色抑制着色） |

### 3. 致死突变导致的非常规比例（和数小于 16）

若双杂合子自交后代比例之和**小于 16**，必定存在致死效应：
1. **显性纯合致死**（如 $AA$ 和 $BB$ 纯合均致死）：
   $$(Aa \times Aa \to 2 Aa : 1 aa) \times (Bb \times Bb \to 2 Bb : 1 bb) \Longrightarrow 4 AaBb : 2 Aabb : 2 aaBb : 1 aabb$$
   表现型比例变为 **$4 : 2 : 2 : 1$**（总和为 9）。
2. **单基因显性纯合致死**（如仅 $AA$ 致死）：
   $$(2 Aa : 1 aa) \times (3 B\_ : 1 bb) \Longrightarrow 6 : 2 : 3 : 1$$
   表现型比例变为 **$6 : 3 : 2 : 1$**（总和为 12）。
3. **隐性纯合双致死**（$aabb$ 致死）：
   表现型比例变为 **$9 : 3 : 3 : 0$** 即 **$9 : 3 : 3$**（总和为 15）。
4. **配子致死**（如含某基因的雄配子致死率 $50\%$）：
   直接写出雌、雄产生的存活配子比例，用**棋盘法（交叉乘积矩阵）**计算，杜绝硬套公式！

## 四、 高频易错点与考场排雷 (WARNING)

> [!WARNING]
> ### 🚨 考场排雷一：两对基因在同一对同源染色体上（连锁问题）
> **【致命陷阱】**：题目给出两对相对性状杂交，$\text{F}_1$ 双杂合子自交后代出现 $3:1$ 或 $1:2:1$，考生习惯性以为是“基因突变”或“致死”，忽略了**连锁（Linkage）**。
> - **本质**：自由组合定律的前提是**基因位于非同源染色体上**。若两对等位基因位于同一对同源染色体上（如 $A$ 与 $B$ 连锁，$a$ 与 $b$ 连锁），在不考虑交叉互换时，$\text{F}_1$ 只能产生 2 种配子（$AB : ab = 1:1$），自交后代表型比为 **$3:1$**，测交后代为 **$1:1$**。

> [!WARNING]
> ### 🚨 考场排雷二：混淆“亲本类型”与“重组类型”的定义
> **【致命陷阱】**：做题时，许多考生默认黄色皱粒和绿色圆粒一定是“重组类型”。
> - **排雷策略**：重组类型是**相对于亲本表现型**而言的！
>   - 若亲本为：黄色圆粒 $\times$ 绿色皱粒，则重组类型为：**黄色皱粒 + 绿色圆粒**（占 $\frac{3}{16} + \frac{3}{16} = \frac{3}{8}$）；
>   - 若亲本为：黄色皱粒 $\times$ 绿色圆粒，则重组类型为：**黄色圆粒 + 绿色皱粒**（占 $\frac{9}{16} + \frac{1}{16} = \frac{5}{8}$）！审题必须看清杂交亲本的初始表型！

## 五、 高考真题命题角度与长句表达规范

### 1. 探究两对等位基因是否位于非同源染色体上的实验设计模板

> **【真题设问】**：已知某植物的花色受两对独立遗传的等位基因控制。现有纯合紫花和纯合白花植株若干，请设计实验探究这两对基因是否位于非同源染色体上。（写出简要实验思路、预期结果与结论）

**【规范满分作答模板】**：
- **实验思路**：
  让纯合紫花植株与纯合白花植株杂交获得 $\text{F}_1$，$\text{F}_1$ 植株进行**自交（或与隐性纯合白花植株测交）**，观察并统计子代（$\text{F}_2$）的花色表现型及比例。
- **预期结果与结论**：
  1. 若 $\text{F}_2$ 表现型比例符合 **$9:3:3:1$（或其变式如 $9:7$、$9:3:4$、$15:1$ 等，各比例之和等于 16）**（若为测交，则为 $1:1:1:1$ 或其变式且之和为 4），则说明两对等位基因**分别位于两对非同源染色体上**，遵循自由组合定律；
  2. 若 $\text{F}_2$ 表现型比例不符合上述比例之和（出现 $3:1$ 或 $1:2:1$），则说明两对等位基因**位于同一对同源染色体上**，不遵循自由组合定律。
