# 03 伴性遗传与遗传系谱图三步排查法

> **【导读与第一性原理】**
> - **教材坐标**：必修2 第2章 第2节《基因在染色体上》、第3节《伴性遗传》
> - **核心生命观念**：结构与功能观、演化与适应观、逻辑推理与排查思维
> - **认知引导**：为什么色盲患者绝大多数是男性？为什么抗维生素D佝偻病在女性中更为普遍？为什么有些性状只在雄性中代代相传？答案深植于性染色体的物理形态差异：异型性染色体（X 与 Y）在亿万年的演化中失去了绝大部分同源配对序列。基因不仅是抽象的符号，而是物理锚定在染色体特定区段上的实体。本节将从染色体形态学与演化第一性原理出发，构建现代高考遗传系谱图判定的终极杀器——升级版“三步排查法”。

## 一、 教材基础与伴性遗传微观机理

### 1. 基因在染色体上的实验证明──摩尔根果蝇杂交实验

萨顿通过观察减数分裂中染色体与基因的行为平行性，提出了**“基因在染色体上”的假说（类比推理法）**。随后摩尔根利用果蝇白眼突变体，运用严格的**假说-演绎法**给出了无可辩驳的物理证据：

```
摩尔根果蝇红白眼实验演进
P:    红眼雌 (Xʷ⁺Xʷ⁺)  ×  白眼雄 (XʷY)
                │
                ▼
F₁:         红眼雌 (Xʷ⁺Xʷ) 、 红眼雄 (Xʷ⁺Y)
                │ ⊗ (自交)
                ▼
F₂:   红眼雌 : 红眼雄 : 白眼雄 = 2 : 1 : 1
     (所有白眼个体均为雄性！表现出与性别的强关联)
```

- **摩尔根假说**：控制白眼的基因 $w$ 是隐性基因，**只位于 X 染色体上，Y 染色体上没有其等位基因**。
- **测交验证**：白眼雌 ($X^wX^w$) $\times$ 红眼雄 ($X^WY$) $\to$ 子代红眼雌 ($X^WX^w$) : 白眼雄 ($X^wY$) = $1 : 1$。实验结果与假说完美契合，彻底证实了**基因位于染色体上**。

---

### 2. 性染色体形态与三大区段图谱

在 XY 型性别决定的生物（如果蝇、人类、哺乳动物）中，X 与 Y 染色体形态差异极大，但在减数分裂联会时可分为三个物理区段：

1. **Ⅰ 区段（X 特有区段 / X 非同源区段）**：
   - Y 染色体上无对应等位基因；
   - 雌性基因型：$X^AX^A$、$X^AX^a$、$X^aX^a$；雄性基因型：$X^AY$、$X^aY$（雄性只含一个基因即可直接显现表型，称为**半合子**）。
   - 典型疾病：红绿色盲、血友病（伴 X 隐性）；抗维生素 D 佝偻病（伴 X 显性）。
2. **Ⅱ 区段（X-Y 同源区段）**：
   - X 和 Y 染色体上均有对应的等位基因；
   - 基因型表示如：$X^AY^a$、$X^aY^A$、$X^aY^a$ 等。
   - 特点：虽然位于性染色体上，遵循伴性遗传规律，但若亲本基因组合特殊，在子代中会表现出显著的**性别偏向**。
3. **Ⅲ 区段（Y 特有区段 / Y 非同源区段）**：
   - 仅在雄性中存在，由父亲直接传给儿子，代代相传（**全雄遗传**），如外耳道多毛症。

### 3. 三大典型伴性遗传模式核心特征对照

| 遗传类型 | 典型代表病例 | 性别患病倾斜度 | 核心传递规律（考场铁律） | 典型逆反排除条件 |
| :--- | :--- | :--- | :--- | :--- |
| **伴 X 隐性** | 红绿色盲、进行性肌营养不良、血友病 | **男性患者显著多于女性** | ① 交叉遗传（外公 $\to$ 母亲 $\to$ 外孙）<br>② **母病子必病，女病父必病** | **女病父正** 或 **女病子正** 立即排除！ |
| **伴 X 显性** | 抗维生素 D 佝偻病 | **女性患者显著多于男性** | ① 连续遗传（代代有患者）<br>② **父病女必病，子病母必病** | **男病母正** 或 **男病女正** 立即排除！ |
| **伴 Y 遗传** | 外耳道多毛症 | **全为男性患者，女性绝不患病** | 传男不传女，父传子、子传孙 | 出现任何女性患者或病父生正子立即排除！ |

## 二、 遗传系谱图升级版“三步排查法”深度模型

在面对复杂遗传系谱图（特别是包含“XY 同源区段”干扰的新高考压轴题）时，传统模型极易误判，必须采用升级版三步排查法：

```
升级版三步排查流线图
【第 1 步：判显隐】
  ├── 无中生有 ➔ 隐性遗传病
  └── 有中生无 ➔ 显性遗传病
          │
          ▼
【第 2 步：找突破口排除 仅X / 仅Y / 母系】
  ├── 排除母系：母病子正 或 母正子病
  ├── 排除伴 Y：出现女患者，或病父生出正常儿子
  ├── 排除仅 X 隐：寻找“女病” ➔ 若【女病父正】或【女病子正】 ➔ 排除仅 X 隐！
  └── 排除仅 X 显：寻找“男病” ➔ 若【男病母正】或【男病女正】 ➔ 排除仅 X 显！
          │
          ▼
【第 3 步：核心决战──常染色体 vs XY 同源区段】
  ├── 隐性病排除了仅 X 隐后：
  │     ├── 观察到【正常双亲生出病女，但儿子全正常】等极端性别倾斜 ➔ 判定为 XY 同源隐！
  │     └── 男女患病概率均等、发病随机 ➔ 判定为常隐！
  └── 显性病排除了仅 X 显后：
        ├── 观察到【病父 × 正母 ➔ 全男病女正】或【全女病男正】等极端性别对立 ➔ 判定为 XY 同源显！
        └── 子代男女发病随机均等 ➔ 判定为常显！
```

---

### 1. 决战情况 A：隐性病（排除了“仅 X 隐”后的常隐 vs XY 同源隐抉择）

- **核心突破口**：寻找谱系中的**隐性纯合雌性（病女）**或**正常双亲生出患病后代**的家庭。
- **XY 同源隐性机制**：雄性父亲基因型可为 $X^aY^A$（携带致病隐性基因，但表现正常）。若母亲为杂合携带者 $X^AX^a$：
  $$P: X^AX^a \times X^aY^A \implies \text{子代女儿 } X^AX^a(\text{正}) : X^aX^a(\textbf{患病}) = 1:1, \quad \text{子代儿子 } X^AY^A(\text{正}) : X^aY^A(\textbf{全部正常})$$
- **关键结论**：若图谱中出现**正常双亲生出患病女儿，而儿子无论生几个全部正常（或表现出极端的性别锁定）**，高度指向 **XY 同源区段隐性遗传**；若男女患病概率均等无偏向，则为**常染色体隐性**。

---

### 2. 决战情况 B：显性病（排除了“仅 X 显”后的常显 vs XY 同源显抉择）

- **核心突破口**：寻找谱系中的 **患病雄性（显性杂合） $\times$ 正常雌性（隐性纯合 $X^aX^a$）**。
- **决定性机制分析**：患病父亲携带的显性基因 $A$ 既可能在 X 上，也可能在 Y 上：
  1. 若父为 $X^AY^a$ $\times$ 母 $X^aX^a$：
     $$\text{后代女儿全部为 } X^AX^a(\textbf{全病})，\quad \text{后代儿子全部为 } X^aY^a(\textbf{全正常})$$
  2. 若父为 $X^aY^A$ $\times$ 母 $X^aX^a$：
     $$\text{后代女儿全部为 } X^aX^a(\textbf{全正常})，\quad \text{后代儿子全部为 } X^aY^A(\textbf{全病})$$
- **关键结论**：只要观察到**患病父亲与正常母亲结婚，后代表现出“全男病、全女正”或“全女病、全男正”的极端两极分化**，直接锁定 **XY 同源区段显性遗传**；若儿女均有发病且比例随机，则为**常染色体显性**。

## 四、 考场排雷与高频陷阱指南

> [!WARNING]
> ### 陷阱 1：“患病男孩” vs “男孩患病” 的概率概率分母陷阱
> 这是高考遗传计算中最易失分的统计陷阱：
> 1. **“生一个患病男孩”的概率**：指在**所有未出生的子代整体（不分性别）**中，既是男孩又患病的概率。
>    $$P(\text{患病男孩}) = P(\text{男孩}) \times P(\text{该男孩患病}) = \frac{1}{2} \times P(\text{病}) \quad (\text{常染色体或伴性需视具体基因型})$$
> 2. **“生下的男孩患病”的概率**：指**已知性别为男性**（已限定在男孩群体中），该男孩患病的条件概率。
>    $$P(\text{患病} \mid \text{男孩}) = \frac{P(\text{男性患病个体})}{P(\text{男性个体总数})}$$
> - **秒杀口诀**：性别在后（患病男孩），乘上 $1/2$（常染色体时）；性别在前（男孩患病），分母为男。

> [!WARNING]
> ### 陷阱 2：如何用杂交实验区分基因位于“常染色体”还是“X 染色体特有区段”？
> - **标准方案（一次杂交搞定）**：选择 **隐性纯合雌性 $\times$ 显性纯合雄性**。
>   - 若基因位于 **X 染色体**特有区段：$X^aX^a \times X^AY \to$ **雌性全为显性 ($X^AX^a$)，雄性全为隐性 ($X^aY$)**（后代表现型与性别严格关联）；
>   - 若基因位于 **常染色体**上：$aa \times AA \to$ **子代无论雌雄全部表现为显性 ($Aa$)**。

## 五、 高考生物规范答题长句模板

### 1. 否定致病基因位于 X 染色体非同源区段的标准长句
- **试题情境**：在遗传系谱图中，为何可以确定该隐性遗传病的致病基因不在 X 染色体非同源区段？
- **满分答题规范**：
  > 假设致病基因位于 X 染色体非同源区段上，则**女患者（$X^aX^a$）的父亲和儿子必为患者（$X^aY$）**；但系谱图中出现**患病女性（如 Ⅱ-4）的父亲/儿子表型正常**，与该规律产生矛盾，因此该致病基因不可能位于 X 染色体非同源区段。

### 2. 探究基因位于常染色体还是 XY 同源区段的实验设计长句
- **试题情境**：已知某突变基因可能位于常染色体或 XY 同源区段，请选用纯合野生型与突变型果蝇为材料，设计杂交实验并预期结果。
- **满分答题规范**：
  > **实验方案**：让**纯合隐性雌果蝇**与**纯合显性雄果蝇**杂交得 $F_1$，$F_1$ 雌雄果蝇随机交配得 $F_2$，观察并统计 $F_2$ 果蝇的表现型及性别比例。<br>
  > **预期结果与结论**：若 $F_2$ 中**隐性性状全部出现在雄性个体中（雌性全为显性）**，则该基因位于 **XY 同源区段**（亲本为 $X^aX^a \times X^AY^A \to F_1: X^AX^a \times X^aY^A$）；若 $F_2$ 中**雌雄个体中显隐性比例均为 3:1**，则该基因位于**常染色体**上。
