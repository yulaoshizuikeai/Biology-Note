# 关于 高考生物知识库

> 欢迎来到 **Yulaoshizuikeai's Biology Note (高考生物知识库)**！
>
> 这是一个开源、现代化、结构严谨的高中生物学科知识库与高考全流程复习指南。

---

## 🎯 项目愿景与宗旨

1. **生命观念与科学思维并重**：破除对生物学科“死记硬背”的刻板印象，从结构与功能观、进化与适应观、稳态与平衡观、物质与能量观四个维度打通生命系统的底层逻辑。
2. **公式推导与定量计算精讲**：系统梳理蛋白质脱水缩合、光合呼吸净量真量、DNA 复制与中心法则、遗传变式概率、种群增长模型与生态能量流转等计算难点。
3. **图解即直觉（SVG 矢量化图解）**：拒绝低清模糊截图，全书配备统一规范的高保真矢量图解，涵盖细胞结构、生理通路、系谱图、生态金字塔与基因工程工具。
4. **Docs as Code 工业化产出**：支持在线响应式阅读，更支持一键无损编译为全套教材级矢量高清 PDF。

---

## 🧭 知识体系架构

本知识库分为 **16 大核心专题**，完全对齐人教版高中生物新课标教材与高考考纲：

1. **01 走进细胞与组成细胞的分子**
2. **02 细胞的基本结构与物质跨膜运输**
3. **03 细胞代谢与能量供应（酶、ATP与呼吸光合）**
4. **04 细胞的生命历程（增殖、分化、衰老与凋亡）**
5. **05 孟德尔遗传规律与伴性遗传**
6. **06 基因的本质与中心法则（复制、转录与翻译）**
7. **07 生物的变异、育种与现代生物进化理论**
8. **08 人体内环境与稳态**
9. **09 动物生命活动的神经、体液与免疫调节**
10. **10 植物生命活动的激素调节**
11. **11 种群、群落与生态系统结构功能**
12. **12 人与环境及生态工程**
13. **13 传统发酵技术与微生物培养应用**
14. **14 细胞工程（植物与动物细胞工程）**
15. **15 基因工程与生物技术安全性与伦理**
16. **16 高中生物经典实验专题与科学探究方法**
